# 🐾 Kimcanko Adoption Platform

A modern and responsive web platform designed to support international pet adoption for a Turkey-based animal rescue organization.

👉 Live: https://anabeatrizdeveloper.github.io/adoption-site/

---

## ✨ Overview

This project was developed to improve how rescue animals are presented online, making it easier for potential adopters to explore pets and connect with the organization.

The focus was on **clarity, usability, and scalability**, ensuring the platform can be easily maintained and expanded by non-technical teams.

---

## 🚀 Key Features

- 🐶🐱 Filter system (Dogs / Cats)
- 🏷 Dynamic status system (Available, Reserved, Adopted)
- 📄 Individual pet profile pages
- 🖼 Interactive image gallery with full-size view
- 🎥 Video support for each pet
- 📱 Fully responsive design
- 🔗 Direct contact integration (Email & Instagram)

---

## 🧠 Technical Approach

- Structured all pet data in a single centralized file (`data.js`)
- Built a dynamic rendering system using JavaScript
- Designed reusable components for scalability
- Focused on clean UI and consistent layout across devices

---

## 🎯 Problem & Solution

**Problem:**  
The organization lacked a structured and scalable way to present pets for international adoption.

**Solution:**  
Developed a clean, user-friendly platform that:
- improves visibility of each animal  
- simplifies content updates  
- supports long-term use by external teams
